# 2026-11-19 : Branchement de l'écran TFT ST7789 et correction des couleurs

**Séance :** planifiée · **Durée :** à compléter

## Fait

### Branchement du TFT ST7789

L'écran s'allume, mais l'image est bruitée. Erreur dans le code : on avait mis
`140` au lieu de `240` pour la largeur.

```cpp
tft.init(240, 320, SPI_MODE3);
```

Une fois corrigé, l'affichage est propre… mais le disque censé être **jaune sur
fond blanc** s'affiche en **bleu**.

### Recherche du problème de couleurs

| Essai                                         | Résultat                         |
|-----------------------------------------------|----------------------------------|
| Premiers essais sur les couleurs              | Disque rouge, vert ou violet sur fond blanc, jaune sur fond noir |
| `SPI_MODE0`                                   | Écran reste blanc                |
| `SPI_MODE2`                                   | Écran reste blanc                |
| Forcer le format couleur en 16 bits           | Disque bleu                      |
| Échanger rouge et bleu (RGB565 → BGR565)      | Disque rouge                     |
| Version compacte de l'échange rouge/bleu      | Disque rouge                     |
| Trois cercles test (jaune, cyan, magenta)     | Bleu, rouge, vert                |
| Inverser tous les bits de la couleur (`~c`)   | ✅ Disque **jaune**              |

Fonction testée pour échanger le rouge et le bleu (sans toucher au vert ni à
l'ordre des octets) :

```cpp
uint16_t colorBGR(uint16_t color) {
  uint16_t r = (color & 0xF800) >> 11; // extrait le rouge
  uint16_t g = (color & 0x07E0);       // garde le vert intact
  uint16_t b = (color & 0x001F) << 11; // extrait le bleu
  return b | g | r;                    // recompose en BGR565
}
```

Test des trois cercles côte à côte, pour voir lequel sort en jaune :

```cpp
tft.fillCircle(60,  250, 20, 0xFFE0); // jaune   -> affiché bleu
tft.fillCircle(120, 250, 20, 0x07FF); // cyan    -> affiché rouge
tft.fillCircle(180, 250, 20, 0xF81F); // magenta -> affiché vert
```

Chaque couleur affichée est la **complémentaire** de celle demandée. D'où le test
qui a fonctionné :

```cpp
#define COULEUR(c) (~(c))
```

Seules les couleurs étaient inversées, pas le noir et le blanc : `COULEUR()`
n'était donc appliquée qu'au cercle.

### Solution retenue

Plutôt que d'inverser chaque couleur à la main, on désactive l'inversion
directement dans l'écran :

```cpp
tft.invertDisplay(false);
```

On peut alors utiliser les couleurs normalement (`ST77XX_YELLOW`,
`ST77XX_WHITE`…) dans les commandes `fill`, et le cercle est bien jaune.

> 📷 *Image à ajouter : cercle jaune sur fond blanc*

## Pourquoi

Le test des trois cercles a montré que l'écran affichait la couleur
complémentaire de celle demandée : l'écran inversait les couleurs. Corriger avec
`invertDisplay(false)` règle le problème à la source, au lieu d'ajouter
`COULEUR()` autour de chaque couleur dans le code.
